### 1. Executive Summary & Core Hypothesis

Deploying autonomous robots to solve long-horizon, sparse-reward manipulation tasks requires bridging the semantic gap between high-level human intent (natural language instructions), formal planning specifications (symbolic logic), and low-level continuous motor control. Pure end-to-end reinforcement learning struggles with catastrophic sample complexity and credit assignment over extended horizons, while Large Language Model (LLM) planners frequently hallucinate physically infeasible action sequences or fail to ground actions in continuous physical environments.

The authors hypothesize that long-horizon robotic tasks can be solved with formal trustworthiness and high executability by unifying:
1. **LLM-guided symbolic task planning** formalized in Planning Domain Definition Language (PDDL),
2. **SMT-based formal verification** operating in a closed "Guess-Check-Critique" Counterexample-Guided Inductive Synthesis (CEGIS) loop, and
3. **Differentiable Behavior Tree (BT) synthesis** that compiles verified high-level symbolic plans into parameterized termination conditions and reactive control sub-trees, co-optimizing continuous sub-policies while building an incremental, reusable skill library.

### 2. Theoretical Framework & Mathematical Formulation

The framework operates across a three-tier hierarchical architecture:

```
[ Natural Language Task ] ──► [ LLM Planner (Guess) ] ──► Candidate PDDL Plan
                                        │
                                        ▼
                         [ SMT Verifier (Check) ] ◄── Domain Axioms & Invariants
                                        │
                                        ├─ Counterexample (Unsound) ──► [ Prompt Critique ] ──┐
                                        │                                                     │
                                        ▼ (Verified Sound)                                    ▼
                         [ Differentiable BT Compiler ]                           (Refine Plan)
                                        │
                 ┌──────────────────────┴──────────────────────┐
                 ▼                                             ▼
     [ Symbolic Termination Bounds ]               [ Low-Level Skill Subnets ]
     Parameterized Conditions C_k(s; phi)          Differentiable Policies pi_theta(a|s)
                 │                                             │
                 └──────────────────────┬──────────────────────┘
                                        ▼
                         [ Co-Optimization via Policy Gradients ]
                                        │
                                        ▼
                         [ Incremental Reusable Skill Library ]
```

- **Tier 1 — High-Level Symbolic Planning & PDDL Abstraction:**
  The natural language goal $\mathcal{G}_{\text{NL}}$ and perceived scene state $\mathcal{S}_{\text{scene}}$ are prompted to an LLM to generate a symbolic planning problem in PDDL:
  $$\mathcal{P}_{\text{PDDL}} = (\mathcal{D}, \mathcal{I}, \mathcal{G}), \quad \text{where } \mathcal{D} = (\mathcal{P}, \mathcal{A}_{\text{sym}})$$
  comprising predicates $\mathcal{P}$ (e.g., `on(A, B)`, `holding(cup)`), atomic actions $\mathcal{A}_{\text{sym}}$ with preconditions $\text{Pre}(a)$ and effects $\text{Eff}(a)$, initial state $\mathcal{I}$, and goal state $\mathcal{G}$.

- **Tier 2 — The "Guess-Check-Critique" SMT Verification Loop (CEGIS):**
  High-level plan candidates $\pi_{\text{sym}} = (a_1, a_2, \dots, a_T)$ generated by the LLM are checked by an SMT solver (e.g. Z3) against domain validity constraints and safety invariants:
  $$\Phi_{\text{valid}} = \mathcal{I} \wedge \bigwedge_{t=1}^T \Big(\text{Pre}(a_t, s_{t-1}) \wedge \text{Eff}(a_t, s_t)\Big) \wedge \mathcal{G}(s_T)$$
  $$\Phi_{\text{safe}} = \bigwedge_{t=0}^T \text{Inv}_{\text{safety}}(s_t)$$
  If the formula is unsatisfiable ($\neg(\Phi_{\text{valid}} \wedge \Phi_{\text{safe}})$), the solver extracts an unsat core and a concrete counterexample trace $\mathbf{e}_{\text{fail}}$. The counterexample is translated into a structured natural language critique prompting the LLM to refine the PDDL plan until a mathematically proven valid plan is obtained.

- **Tier 3 — Differentiable Behavior Tree Compilation & Co-Optimization:**
  Once a discrete plan is verified sound, its step-wise preconditions and postconditions compile into parameterized condition leaves and Sequence/Fallback subtrees of a **Differentiable Behavior Tree** (extending Huang et al., NeuS 2025):
  - Return status is relaxed into continuous simplex probabilities $\mathbf{s}(v) = [p_{\text{succ}}, p_{\text{fail}}, p_{\text{run}}]^\top \in \Delta^2$.
  - Continuous t-norms propagate status through Sequences: $p_{\text{succ}}(\text{Seq}) = \prod_k p_{\text{succ}}(v_k)$.
  - Low-level parameterized neural policies $\pi_\theta(a \mid s, v)$ within leaf nodes execute continuous trajectory control, bounded by parameterized termination condition thresholds $\phi$:
    $$p_{\text{succ}}(C_k) = \sigma\left(\frac{f_\phi(s) - \tau_{\text{term}}}{\tau}\right)$$
  - Continuous co-optimization optimizes leaf policy weights $\theta$ and condition boundaries $\phi$ end-to-end via policy gradients driven by sparse task completion and dense sub-goal progress rewards:
    $$\mathcal{L}(\theta, \phi) = -\mathbb{E}_{\tau}\left[R_{\text{task}}(\tau) + \sum_{k} R_{\text{subgoal}}(s_k; \phi)\right] + \lambda_{\text{align}} \mathcal{L}_{\text{semantic}}(\theta, \pi_{\text{sym}})$$

- **Tier 4 — Incremental Skill Library:**
  Successfully synthesized sub-trees that satisfy preconditions and achieve target postconditions are certified, abstracted into modular composite skills, and stored in a persistent library $\mathcal{L}_{\text{skill}}$ for zero-shot reuse in future long-horizon tasks.

### 3. Architecture & Neural Integration

- **Neural Role:**
  1. **Generative LLM Planner:** Zero-shot / few-shot foundation model (e.g., GPT-4o / Claude 3.5 Sonnet) translating natural language tasks into symbolic PDDL representations.
  2. **Differentiable Continuous Leaf Policies:** Multi-layer perceptrons (MLPs) and vision-based policy networks (Diffusion / Gaussian MLP heads) executing motor skills (e.g., grasping, insertion, articulated object manipulation).
- **Interface / Boundary:**
  - High-to-Mid Boundary: Formal PDDL action sequences compile deterministically into Behavior Tree Sequence ($\to$) structures with Fallback ($?$) recovery branches.
  - Mid-to-Low Boundary: Condition leaves in the BT evaluate continuous sensory states $s$ to trigger and terminate low-level continuous policy executions.

### 4. Empirical Evaluation & Benchmarks

- **Environments / Tasks:**
  - **RLBench / Franka Manipulation:** Multi-step long-horizon manipulation benchmarks (e.g., "Sort colored blocks into matching drawers and close drawers", "Prepare table by placing cup and pouring water", "Tool use and obstacle avoidance").
  - **VirtualHome / Habitat:** High-level household task execution with symbolic task dependencies and spatial constraints.
- **Baseline Comparisons:**
  - **SayCan (Ahn et al., 2022):** LLM affordance-conditioned planning without formal verification.
  - **ProgPrompt (Singh et al., 2023):** Programmatic LLM prompt planning without execution-guided BT compilation.
  - **Text2Motion (Lin et al., 2023):** Geometric and kinematic feasibility-guided planning.
  - **Diff-BT (Huang et al., NeuS 2025):** Standalone differentiable BT synthesis without high-level symbolic planning or SMT verification.
  - **Monolithic RL (PPO / SAC):** End-to-end deep reinforcement learning.
- **Key Quantitative Results:**
  - *Task Success Rate:* Reached **88.4% success rate** on complex 6-to-10 stage manipulation tasks in RLBench, significantly outperforming SayCan (52.1%) and ProgPrompt (58.7%).
  - *Planning Validity:* The SMT "Guess-Check-Critique" loop reduced plan execution invalidity / collision failures from 34.2% (unverified LLM) to **0.0% at the symbolic plan level**.
  - *Sample Efficiency:* Reusing skills from the incremental library $\mathcal{L}_{\text{skill}}$ accelerated learning on novel downstream tasks by **$4.2\times$** compared to learning from scratch with Diff-BT.

### 5. Failure Modes, Trade-offs & Limitations

- **Interpretability Preservation:** High interpretability at the macro level: the high-level plan is human-readable PDDL, the execution structure is an explicit Behavior Tree, and verification counterexamples provide transparent diagnostics.
- **Scalability & SMT Solver Bounds:** As task horizon and the number of discrete objects scale ($> 30$ objects), SMT solving time for the Guess-Check-Critique loop grows super-linearly, occasionally timing out on deeply nested domain axioms.
- **Discretization Gap in Neural Leaves:** While high-level plan compilation eliminates macro-level topological ambiguity, low-level neural policies still experience minor performance degradation when transitioning from soft t-norm co-optimization to discrete hardware execution ticks.
- **Physical Dynamics Real-Time Gap:** The SMT verification loop verifies discrete symbolic preconditions (e.g., `path_clear = true`), but does not perform real-time continuous collision checking or dynamic forward invariance (e.g., Control Barrier Functions) against unexpected moving dynamic obstacles.

### 6. Relevance & Critical Assessment for Flow2BT Distillation

- **Complementary Hierarchy:**
  - Huang et al. (PLDI 2026) operates from the **top down** (Natural Language $\to$ PDDL $\to$ SMT $\to$ Differentiable BT), which is ideal for multi-stage discrete robotic task planning.
  - Flow2BT operates from the **bottom up** (Continuous Trajectory Ensembles $\to$ Flow Matching $\to$ Reverse-Time Contraction $\to$ DMPs $\to$ CBF-QP), which is ideal for continuous multi-agent locomotion, agile reactivity, and kinetic collision avoidance.
- **Cross-Pollination Potential:**
  - *High-Level Orchestration:* For robotic navigation missions with complex symbolic goals (e.g. "Deliver cargo to Room B without entering Zone C"), Huang et al.'s SMT-verified PDDL compiler can serve as the high-level mission generator, emitting dynamic waypoints $\mathbf{c}_{t, \text{nav}}$ to Flow2BT.
  - *Low-Level Mechanics Replacement:* Huang et al.'s neural network leaf policies (which require GPU inference and suffer from continuous latency) can be replaced with Flow2BT's **closed-form Dynamical Movement Primitives (DMPs)** and **real-time CBF-QP filters**, cutting runtime latency by $10\times - 50\times$ while providing formal physical collision invariance.
