- **Year / Venue:** 2019 / International Conference on Learning Representations (ICLR 2019)

---

### 1. Executive Summary & Core Hypothesis

Imitation learning and policy extraction typically require either dense action annotations, predefined sub-goal milestones, or hand-engineered task grammars. The authors hypothesize that multi-stage agent behavior can be compiled into an interpretable, hierarchical program-like execution policy directly from unlabelled, continuous state sequences $\tau = (x_1, \dots, x_T)$ in a completely unsupervised manner. 

By formulating program compilation as an unsupervised variational sequence auto-encoding problem with **differentiable temporal boundary detection** and **discrete latent sub-program assignment**, COMPILE simultaneously learns:
1. When a high-level task phase terminates (discovering Sequence node transitions), and
2. Which reusable sub-routine / primitive policy was executed (discovering leaf action identities),
all via end-to-end gradient backpropagation without human annotations.

---

### 2. Theoretical Framework & Mathematical Formulation

- **Input Format:** Continuous, unsegmented, unlabelled state-action trajectory sequences:
  $$\tau = (x_1, x_2, \dots, x_T), \quad x_t \in \mathbb{R}^d$$
  No sub-routine boundaries, no sub-goal labels, and no symbolic program supervision.
- **Variational Generative Framework:**
  COMPILE assumes demonstrations are generated by executing an underlying hierarchical program consisting of an ordered sequence of $K$ discrete latent sub-programs $z_{1:K} = (z_1, \dots, z_K)$, where each sub-program $z_k \in \{1, \dots, C\}$ is active for a dynamic duration $\ell_k \ge 1$ with $\sum_{k=1}^K \ell_k = T$.
  
  The joint generative model factorizes as:
  $$p_\theta(x_{1:T}, z_{1:K}, b_{1:T}) = p(z_{1:K}) p(b_{1:T}) \prod_{t=1}^T p_\theta(x_t \mid x_{<t}, z_{k(t)})$$
  where $b_t \in \{0, 1\}$ is a binary boundary indicator marking the transition between sub-programs, and $k(t) = 1 + \sum_{s=1}^{t-1} b_s$ tracks the active sub-program index.

- **Differentiable Inference Network (Encoder):**
  To enable gradient backpropagation through discrete execution boundaries and program selections:
  1. **Continuous Attention Gating for Boundaries:** The posterior boundary probability is parameterized via a recurrent attention mechanism:
     $$q_\phi(b_t = 1 \mid x_{1:T}, b_{<t}) = \sigma\big(W_b h_t + b_b\big)$$
     Soft boundary weights allow gradients to flow across temporal step boundaries.
  2. **Discrete Latent Program Sampling:** Sub-program tokens $z_k$ are inferred from the segmented temporal window and relaxed using the **Gumbel-Softmax (Concrete) distribution**:
     $$q_\phi(z_k \mid x_{1:T}, b_{1:T}) = \text{Softmax}\left(\frac{\log \pi_k + g}{\tau_{\text{temp}}}\right), \quad g \sim \text{Gumbel}(0, 1)$$
  3. **Bidirectional Temporal Encoding:** The trajectory is processed using a bidirectional RNN / Transformer, ensuring that the inferred program $z_k$ incorporates both past context and future trajectory trends.

- **Optimization Objective:**
  The model is optimized end-to-end by maximizing the Evidence Lower Bound (ELBO):
  $$\mathcal{L}_{\text{ELBO}}(\theta, \phi) = \mathbb{E}_{q_\phi(z, b \mid x)}\left[\sum_{t=1}^T \log p_\theta(x_t \mid x_{<t}, z_{k(t)})\right] - D_{\text{KL}}\big(q_\phi(z \mid x) \,\|\, p(z)\big) - D_{\text{KL}}\big(q_\phi(b \mid x) \,\|\, p(b)\big)$$

---

### 3. Architecture & Neural Integration

- **Neural Role:** Deep recurrent networks (bidirectional LSTMs / GRUs) parameterize both the inference encoder $q_\phi$ and the generative sequence decoder $p_\theta$.
- **Interface / Boundary:** Latent tokens $z_k$ serve as the discrete symbolic bottleneck. At test time, the continuous latent variable is discretized to an argmax categorical token $z_k^*$, extracting an interpretable high-level execution script:
  $$\text{Program} = \big[\text{SubRoutine}_{z_1}, \, \text{SubRoutine}_{z_2}, \, \dots, \, \text{SubRoutine}_{z_K}\big]$$
  where each $\text{SubRoutine}_c$ governs low-level continuous state transitions.

### 4. Empirical Evaluation & Benchmarks

- **Environments / Tasks:**
  - Multi-task GridWorld (agent collects keys, opens colored doors, navigates mazes).
  - Continuous 2D Particle Dynamics (pushing objects to designated targets with obstacles).
  - Multi-stage block manipulation and stacking tasks.
- **Baseline Comparisons:**
  - Neural Program Induction (NPI).
  - Unsupervised Hierarchical RNNs (HRNN).
  - Option-Critic architectures (Sutton et al.).
  - Variational Autoencoders without boundary gating.
- **Key Quantitative Results:**
  - Recovered the **exact ground-truth program sequence with $>98\%$ accuracy** across diverse unseen demonstrations.
  - Successfully discovered reusable, modular sub-routines (e.g., "Navigate to Green Door", "Pick Key") without any textual or symbolic supervision.
  - Outperformed Option-Critic on sub-goal transfer and long-horizon imitation stability.

---

### 5. Failure Modes, Trade-offs & Limitations

- **Interpretability Preservation:** High at the macro-level (clear sequential ordering of modular sub-tasks); medium at the leaf level (sub-routine leaves remain neural decoders rather than closed-form physical equations like DMPs).
- **Scalability & Gradient Stability:** Training requires careful annealing of the Gumbel-Softmax temperature $\tau_{\text{temp}}$ and boundary threshold. If temperature drops too rapidly, the model collapses into degenerate solutions (e.g., setting all $b_t = 0$ or all $b_t = 1$).
- **Unaddressed Gaps:** COMPILE extracts sequential programs (equivalent to a top-level Behavior Tree **Sequence** node $\to$); it does not explicitly generate branching **Fallback** ($?$) recovery logic for handling environmental faults.

---

### 6. Relevance & Critical Assessment for Flow2BT Distillation

- **Resolution of the Decodability Gap:** COMPILE provides the exact solution to the **State-Decodability Bottleneck** documented in Flow2BT (`IMPLEMENTATION_FINDINGS.md` §4.6):
  - In Flow2BT, static SVM condition guards failed ($54\%$ routing fidelity) because trajectories diverged due to future interactions not observable at $t=0$.
  - COMPILE uses **bidirectional sequence encoding over full trajectory rollouts** during the discovery phase. This ensures that latent mode assignments are grounded in full temporal behavior. Once segments are properly clustered, causal pre-conditions can be trained with high stability.
- **Decision Trees vs. Behavior Trees Gap:** COMPILE recovers temporal Sequence composition ($\to$); combining COMPILE's unsupervised temporal segmentation with RE:BT-Espresso's logic minimization provides the full structural pipeline: COMPILE discovers *when and what* sub-tasks execute, while RE:BT-Espresso discovers the *reactive fallback guards* between them.
- **Compatibility with Flow2BT Subsystems:**
  - **Subsystem 3 (Topological Induction):** COMPILE's differentiable boundary detector can segment continuous flow-teacher trajectories $\dot{x} = v_\theta(x, t)$ into natural sub-movement phases without requiring heuristic navmesh waypoint heuristics.
  - **Subsystem 5 (DMP Leaf Fitting):** Once COMPILE partitions continuous trajectories into discrete sub-programs $z_k$, each partition is unimodal and can be directly fit by a 2nd-order DMP.
